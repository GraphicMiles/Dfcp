This runs entirely in the browser via getUserMedia, so it can't do raw-sensor access, manual exposure lock, or rolling-shutter row demodulation — those need Camera2 / AVFoundation in a native app. What it can measure honestly: symbol density vs. decode error rate, and effective throughput, across real distance / lighting / alignment conditions. Use it to find where reliability breaks down before committing to a density target.
